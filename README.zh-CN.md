# dsh-chat-screenshot

把一段对话渲染成一张 PNG 放进剪贴板的 DeepSeek Harness 插件，画面长什么样由你决定。

[English](README.md) | 中文

相机在输入框的工具条里。点一下复制整段对话，右键菜单可以把画面收窄到最后一轮，或者你在列表里勾选的那几轮。每条回复也有自己的相机，一问一答就是一张图。浏览器不允许写剪贴板时，改为下载文件。

画面没有任何一处是写死的。打开编辑面，对话本身成为画布：会进入图片的每个元素都在那儿，由你决定留谁、去谁、上下加什么、怎么画。编辑面和截图是同一条构建路径，所以编辑时看到的，就是 PNG 里的。

## 安装

```bash
dsh plugin --profile web add D:\Projects\Agent\DSH\Plugin\ChatScreenshot
```

卸载：

```bash
dsh plugin --profile web remove dsh-chat-screenshot
```

插件 id 是 `dsh-chat-screenshot`，装完刷新页面。

## 截图

| 入口 | 位置 | 截什么 |
| --- | --- | --- |
| 整段对话 | 输入框工具条里的相机 | 当前会话的全部内容，先把更早的历史翻完 |
| 单轮 | 某条回复操作行里的相机 | 从开启这一轮的用户消息，到下一轮之前的全部内容 |
| 选定轮次 | 右键输入框相机，选“选择轮次...” | 勾选的那几轮，按阅读顺序叠成一张图 |
| 最后一轮 | 右键输入框相机，选“最后一轮” | 此刻正在看的这一轮，还在流式生成的回复也算 |

两个按钮只有图标，工作时转圈，成功后闪一下对勾，结果报在按钮上方的小条里。右键菜单与轮次选择器用的是应用自己的组件，主题与键盘行为都跟着宿主走。

截图前会先用聊天视图自己的“加载更早”控件把历史翻完。这个控件不会消失：翻到头之后它留在原地、变成禁用、标签换成“已到会话开头”，所以截图读它的可见标签，见底即停。宿主给不出下一页时，截图照常进行，小条里会说明画面只含已加载的轮次。

## 编辑面

设置里的“对话截图”一节打开编辑面，它盖在对话上。所有工具都在底部的托盘里，上面的画面不会被压窄；拖托盘上的手柄可以改高度，双击手柄可以折叠。

- **任何元素都可以收拾。** 在副本里双击任何元素即可隐藏，再双击放回。插件点名认识的那几个控件只是起手的词汇表，插件或新版本往对话里加的东西，同样这条路能到。
- **隐藏是声明，不是删除。** 被隐藏的元素留在副本里、但不占画面，所以图片量出来的就是“它不存在”的样子，而编辑面仍能指向那个洞。
- **清单在元素页。** 藏起来的东西都收在这一页的左栏：单击让它在原位闪现一下，双击彻底放回，也可以一次全部还原。
- **内容可以加在上方或下方。** 组件库只有一张清单——块就是块，插件自带的和你存下的排在一起。“放入位置”决定加到页头还是页脚，加进去的块就地选中，画面立刻变。
- **文本读实时值。** `{turns}` `{prompts}` `{date}` `{time}` `{weekday}` `{title}` `{model}` `{session}` `{app}` `{version}` 在截图时从对话与宿主取；编辑时占位符原样可见，认不出的原样保留。
- **块是可调的，不是写死的。** 分隔线自带粗细与上下留白，间隙自带高度，图片自带宽度与字节，文本自带走字号与对齐。同一批字段也在检查器里，块落在哪就能在哪调。
- **图片不出这个浏览器。** 选中的文件读成 data URL 存进选项，超过 80 万字符直接拒绝，不会偷偷存下。
- **组件。** 组件就是一块带名字的内容。插件自带的五块内容本身就是“系统提供的组件”：和别的条目一样可以放，但归属插件，不能原地改、不能删。点它的 `...` 会带着一份副本打开设计器，存下来就成了你自己的。设计器里每个字段都有名字，预览用的是画面自己的渲染器，存下的条目一直留在清单里。
- **检查器改选中的东西。** 点元素：标签、选择器、隐藏开关、可改的名字、六个样式预设（淡化、描边、去留白、去底色、等宽字体、小字号）以及自由的样式行与属性行。点内容块：各项字段、一个“存成组件”按钮、一个删除按钮。
- **右键任何东西**：隐藏、还原、删掉这个元素的规则、分隔线、信息行、恢复默认。
- **完成**关闭编辑面。每次改动都作用于下一次截图，不用刷新。

托盘分三页：内容（两个区的块）、元素（藏了什么、指针选了谁）、组件库（清单与设计器）。

## 存储

一条规则是 `{ selector, name, hide, style, attrs }`，靠选择器生效，选择器命中的元素都吃这条规则。内容块是 `{ id, kind, zone, ... }`，组件是 `{ id, name, block }`，和规则存在一起。

全部放在本浏览器的 `localStorage`，键 `chat-screenshot.options`。插件不注册宿主配置，服务端不存任何东西。存下的值对不上可选项时退到最近的一档，“恢复默认”回到素净的画面。

## 做不到的事

- 图片里只有对话：没有侧栏、没有输入框、没有第二个会话。
- 超过画布预算（每边约 16000px）时按比例缩小，小条里会写明倍数。
- 只在悬停时出现的控件按实时状态呈现，副本不会强行把它们露出来。
- 大于 256px 的 SVG 图标，或引用外部符号的图标不画，免得解码卡死。

## 实现

1. 把已挂载的应用界面克隆进一个隐藏的舞台，舞台装在一个固定、零尺寸的容器里，页面的滚动几何不受影响，活界面也不会被写。
2. 准备副本：图片去掉懒加载属性，画不出来的媒体丢掉，元素规则以声明的形式落到副本上。
3. 按存下的选项，把上下两区的内容块建进副本，模板变量从对话里取。
4. 从第一轮（或上区）裁到最后一轮（或下区），两端留一样的内边距。
5. 副本塞进 SVG 的 `foreignObject`，以 data URL 解码交给浏览器排版，与屏幕天然一致；解码不成功时，手绘路径读浏览器的盒子与文本行，画到 canvas 上。
6. PNG 进剪贴板；写失败或迟迟不返回时退化为下载，文件名带会话与时刻。

## 目录

| 路径 | 作用 |
| --- | --- |
| `index.js` | 宿主半边：没有可跑的东西，因为加载器条目必须是插件 |
| `src/client/apply.js` | 注册：语言表、样式表、两个入口、设置页 |
| `src/client/shell/` | 常量、React 访问、保存的选项、文案表、样式、截图状态 |
| `src/client/dom/` | 编排：搭副本、量带子、驱动截图 |
| `src/client/dom/clone/` | 在副本上做的一切：准备、规则引擎、模板变量、编辑面加的内容块 |
| `src/client/dom/transcript/` | 读对话：轮次范围、历史分页、几何 |
| `src/client/render/` | 选渲染器、SVG 文档、手绘、裁切、画布预算 |
| `src/client/output/` | 写剪贴板与下载 |
| `src/client/views/` | 按钮本体、右键菜单、轮次选择器、图标、设置页 |
| `src/client/views/editor/` | 编辑面：外框、底部托盘、内容清单、组件设计器、拖拽、检查器、组件库 |
| `src/client/manifest.json` | 打包顺序 |
| `client.js` | 生成的产物，不要手改 |
| `build.mjs` | 把各部分拼成 `client.js` |
| `checks/` | 结构、文案、逻辑校验，以及一个跑 DOM 行为的页面 |

## 开发

```bash
node build.mjs            # 由 src/client 生成 client.js
node build.mjs --watch    # 改了自动重建
npm run check             # 产物新鲜度、结构、文案、逻辑
node checks/serve.mjs     # 然后打开 http://127.0.0.1:8712/checks/dom.html 跑 DOM 校验
```

各部分都是普通的 ESM 模块，node 能单独 import。它们被拼进同一个工厂作用域，所以顶层名字在整个包里必须唯一；即便如此，一个部分仍要 import 它用到的邻居，否则单跑时看不出问题。

所有面向用户的文案都在 `src/client/shell/i18n.js`，注册到客户端的语言服务，切换语言不用刷新。`checks/i18n.mjs` 会在某个键只存在于一种语言、占位符不一致、或视图要了表里没有的键时报错。

`client.js` 的内容版本在打包时定死，重建的包不会自动进入正在跑的宿主：把插件关掉再打开，然后刷新页面。
